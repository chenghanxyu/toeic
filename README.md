# TOEIC 635 → 750+ Week 1

## 使用方式
直接打開 `index.html` 即可使用。

建議瀏覽器：Chrome / Edge / Safari。

## 功能
- Day 1～7 Week 1 課表
- 單字與搭配詞
- Part 5 / Part 2 / Part 3 / Part 4 / Part 7 練習
- 瀏覽器 TTS 聽力播放
- 答題後顯示解析
- 自動統計正確率、技能弱點與作答時間
- localStorage 保存進度
- 匯出 JSON 學習紀錄
- 匯出錯題 CSV

## 如何讓 ChatGPT 幫你調整 Week 2
完成 Day 1 或 Week 1 後，在頁面左下角點：
「匯出學習紀錄 JSON」

把 `toeic_week1_progress.json` 上傳回 ChatGPT，我可以依：
- Part 正確率
- 技能分類
- 作答速度
- 錯題類型

重新配置 Week 2。

## 注意
目前 Listening 使用瀏覽器內建 Speech Synthesis，因此不同裝置的聲音會不同。
這一版目的以「訓練流程＋追蹤」為主，之後可再升級為真人或固定 TTS 音檔。
